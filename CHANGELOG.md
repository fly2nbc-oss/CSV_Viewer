# Changelog

All notable changes to **CSV Viewer** are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-05-06

### Changed

- UI strings standardized to English (tooltips, About dialog, accessibility labels, column statistics).
- Number formatting for statistics uses US locale (`en-US`).
- README restructured for GitHub project page consistency; added community docs (`CONTRIBUTING`, `CODE_OF_CONDUCT`).

## [1.0.0] - Previous release

Initial public release: CSV/TXT/XLSX viewing, search, export to XLSX, virtualized table, light/dark theme.

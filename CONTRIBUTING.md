# Contributing to CSV Viewer

Thank you for your interest in contributing. This project welcomes issues and pull requests.

## How to contribute

1. **Issues** — Bug reports and feature requests are welcome. Please describe steps to reproduce bugs and your environment (OS, app version).
2. **Pull requests** — Fork the repository, create a branch from `main`, and open a PR with a clear description of changes.
3. **Code style** — Follow existing patterns in the repo (`web/` frontend, `src-tauri/` Rust). Run formatting if applicable (`cargo fmt` for Rust).

## Development setup

See [README.md](README.md) — **Development & Build** for prerequisites, `npm install`, and `npm run tauri dev`.

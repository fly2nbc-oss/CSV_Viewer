# CSV Viewer

Desktop Tauri app with CSV/TXT import and XLSX export

## Features

- Open CSV or TXT files
- Drag and drop support
- Auto-detect common delimiters
- Search and row jump
- Virtualized table rendering
- XLSX export

## Requirements

- Node.js
- Rust
- Tauri prerequisites

## Tauri Dev

```bash
npm.cmd install
npm.cmd run tauri dev
```

## Tauri Build

```bash
npm.cmd run tauri build
```

## Notes

Generated folders such as `node_modules` and `src-tauri/target` can be recreated when needed.
